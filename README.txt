BÀI TẬP HTML + CSS + JAVASCRIPT

File:
- index.html: Bài 2 - cửa hàng online, 18 sản phẩm.
- admin.html: Bài 1 - form quản lý/nhập thông tin sản phẩm.
- product.html: trang chi tiết/đặt hàng cho sản phẩm đầu tiên.
- style.css: toàn bộ CSS.
- app.js: dữ liệu sản phẩm + lọc + tìm kiếm + lưu form.

Cách chạy:
1. Giải nén file ZIP.
2. Mở index.html bằng Chrome.
3. Bấm "Quản trị sản phẩm" nếu muốn vào Bài 1.
4. Có thể nộp cả thư mục này cho giáo viên.

Lưu ý:
- Ảnh sản phẩm đang dùng ảnh trực tuyến từ Unsplash nên máy có Internet sẽ hiển thị ảnh.
- Form Bài 1 lưu dữ liệu mẫu vào localStorage của trình duyệt.
